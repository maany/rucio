**Class structure:**

```python
class InfraManager:
    def __init__(self, profile: SuiteProfile, keep_db: bool = False) -> None:
    def setup(self) -> None:  # orchestrates the full sequence; returns immediately if keep_db=True
    def _flush_memcache(self) -> None:  # best-effort TCP to 127.0.0.1:11211
    def _cleanup_temp_files(self) -> None:  # /tmp/.rucio_*, /tmp/rucio_rse, .pyc files
    def _purge_database(self) -> None:  # SQLite file delete OR purge_db() for remote
    def _build_database(self) -> None:  # build_database() from rucio.db.sqla.util
    def _create_base_vo_and_root_account(self) -> None:  # create_base_vo() + create_root_account()
    def _fix_sqlite_permissions(self) -> None:  # os.chmod('/tmp/rucio.db', 0o666)
    def _restart_httpd(self) -> None:  # subprocess httpd -k graceful + 2s sleep
    def _bootstrap_test_data(self) -> None:  # accounts, scopes, multi-VO setup
    def _sync_rses(self) -> None:  # load etc/rse_repository.json, create RSEs via Client
    def _sync_metadata(self) -> None:  # create DID metadata keys via Client
```

**Critical implementation details:**

1. **All rucio imports MUST be lazy** (inside methods, not module level). Rucio modules trigger config loading and DB connections on import. Match existing conftest.py pattern. Only stdlib and `from .profiles import SuiteProfile` at module level (the SuiteProfile import should be TYPE_CHECKING only).

2. **_purge_database logic** (from conftest.py lines 150-205):
   - If `profile.rdbms == "sqlite"`: delete `/tmp/rucio.db` if it exists
   - If `profile.name == "remote_dbs"`: call `purge_db()`, catch exceptions where error contains `'does not exist'` or `'invalidschemaname'` (fresh DB)
   - Otherwise: auto-detect via `get_engine()` URL -- if `'sqlite'` in URL, delete file; else `purge_db()` with same fresh-DB handling

3. **_build_database** (conftest.py lines 208-233): call `build_database()`, `create_base_vo()`, `create_root_account()` in sequence. Wrap in try/except, raise `RuntimeError("Failed to build database")` on failure.

4. **_fix_sqlite_permissions**: Only runs when `profile.rdbms == "sqlite"` or auto-detected as SQLite. Sets `os.chmod('/tmp/rucio.db', 0o666)`.

5. **_restart_httpd** (conftest.py lines 236-247): `subprocess.run(['httpd', '-k', 'graceful'], check=True, capture_output=True)` then `time.sleep(2)`. Catch `FileNotFoundError` (httpd not found outside container). Raise `RuntimeError` on `CalledProcessError`.

6. **_bootstrap_test_data** (conftest.py lines 1187-1255): Extract the `_run_bootstrap_tests()` function exactly. Includes: `reset_config_table()`, multi-VO setup via `add_vo()`, create Client, add accounts (jdoe, panda), add scopes (mock, archive), add admin attributes. Fix the `sys` import bug (line 1227 references `sys.stderr` but `sys` not imported -- add `import sys`).

7. **_sync_rses** (conftest.py lines 1257-1312): Load `etc/rse_repository.json`, iterate RSEs, add RSE + protocols + attributes via Client. Swallow `Duplicate` exceptions.

8. **_sync_metadata** (conftest.py lines 1314-1349): Create metadata keys with the exact list from conftest.py (project, run_number, stream_name, prod_step, datatype, version, campaign, guid, events).

9. **Logging**: Use `print("[infra_manager] ...")` prefix throughout, matching the existing conftest.py `print("[pytest_configure] ...")` pattern but with the new prefix for clarity.

10. **setup() orchestration**: Check `self.keep_db` first, return immediately if True. Otherwise call each step in order. Each step that is critical (purge, build, httpd restart, bootstrap, RSE sync, metadata sync) should fail fast with RuntimeError on error. Memcache flush and temp file cleanup are best-effort.

11. **File header**: Include the standard CERN Apache 2.0 copyright header matching the other files in tests/ruciopytest/.
