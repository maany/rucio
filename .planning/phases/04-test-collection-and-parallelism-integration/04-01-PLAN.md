  <action>
1. In `profiles.py`, add `exclude_paths: tuple[str, ...] = ()` field to `SuiteProfile` after `markers`. Update `resolve_profile` to pass `exclude_paths` through when creating an RDBMS-overridden profile.

2. Create `tests/ruciopytest/collection.py` with:

**Service-to-profile resolution map** (`_SERVICE_TO_PROFILE` dict and `_KNOWN_PROFILES` frozenset):
- Map every service from docker-compose.yml to its compose profile (see 04-RESEARCH.md Pattern 3 for complete mapping)
- Include `_KNOWN_PROFILES` frozenset for self-referencing profile names

**`_resolve_infra(infra_arg: str) -> tuple[set[str], set[str]]`**:
- Split on comma, strip whitespace
- For each name: if in `_KNOWN_PROFILES`, add to profiles set; elif in `_SERVICE_TO_PROFILE`, resolve and add; else raise `ValueError(f"Unknown infrastructure: {name!r}")`
- Return `(resolved_profiles, raw_services)`

**`_infer_suites_from_infra(profiles: set[str]) -> list[SuiteProfile]`**:
- Iterate `SUITE_PROFILES.values()`, check if any of the suite's `compose_profiles` overlap with the given profiles
- Return list of matching suite profiles

**`_item_matches_profile(item: pytest.Item, profile: SuiteProfile) -> bool`**:
- Get relative path via `str(item.path.relative_to(item.config.rootpath))`
- Check `exclude_paths` first (any fnmatch match -> return False)
- Check `test_paths` (any fnmatch match OR path starts with pattern stripped of trailing `*`)
- Check `markers` (any marker present on item)
- Return `path_match or marker_match`

**`pytest_collection_modifyitems(session, config, items)`**:
- Get profile from `config.stash.get(suite_profile_key, None)`. Return early if None (dormant).
- Also return early if `config.stash.get(delegate_to_container_key, False)` is True (host-side delegation skips filtering).
- Build selected/deselected lists using `_item_matches_profile`
- Report deselected via `config.hook.pytest_deselected(items=deselected)` (note: the hook name is `pytest_deselected`, not `pytest_deselection`)
- Modify `items[:] = selected` in-place
- If `--co` (collect-only) or `--dry-run` is active AND verbosity >= 0, print grouping breakdown: tests grouped by inclusion reason (path match, marker match)

**Overlap warning logic**:
- When `--suite` is active, check each selected item against ALL other suite profiles
- If an item matches another suite profile too, collect those warnings
- Print warnings after filtering: "WARNING: {N} tests match multiple suites: {suite1}, {suite2}"
- Show first 5 overlapping test names, then "... and N more"

**`_print_dry_run_report(config, profile, items, deselected)`**:
- If `config.getoption("dry_run", default=False)` is not set, return
- Build report with sections: Infrastructure Plan (compose_profiles, rdbms, services), Test Collection Summary (collected count, deselected count, breakdown by path)
- If `config.getoption("dry_run_json", default=False)`: output `json.dumps(report_dict, indent=2)`
- Else: output structured human-readable text using terminalreporter if available, else print()
- After printing dry-run report, raise `pytest.exit("Dry run complete", returncode=0)` to stop execution

Import `fnmatch`, `json`, `pytest`, and from `.profiles` import `SuiteProfile`, `SUITE_PROFILES`, and from `.plugin` import `suite_profile_key`, `delegate_to_container_key`.

IMPORTANT: To avoid circular imports, import stash keys from plugin lazily or use a shared keys module. Simplest approach: define the stash keys in `collection.py` and import them INTO `plugin.py` (reverse the dependency), OR define stash keys in `__init__.py`. Choose the cleanest option -- recommend moving `suite_profile_key` and `delegate_to_container_key` into `__init__.py` and importing from there in both modules.

   - `--infra`: type=str, default=None, help="Override infrastructure (comma-separated compose profiles or service names)"
   - `--dry-run`: action="store_true", default=False, dest="dry_run", help="Show infrastructure plan and test collection without executing"
   - `--dry-run-json`: action="store_true", default=False, dest="dry_run_json", help="Output dry-run report as JSON (implies --dry-run)"

2. In `pytest_configure`, add logic for `--infra` mode:
   - After the existing `suite_name = config.getoption("suite", default=None)` check
   - Get `infra_arg = config.getoption("infra", default=None)`
   - If `--dry-run-json` is set, implicitly set dry_run=True
   - **If `--infra` without `--suite`:** Import `_resolve_infra` and `_infer_suites_from_infra` from `.collection`. Resolve infra to profiles. Infer matching suites. If no suites match, raise `pytest.UsageError(f"No suites match infrastructure: {infra_arg}")`. Create a synthetic merged profile with the union of test_paths/markers/exclude_paths from all matching suites, using the resolved compose_profiles. Store in stash.
   - **If `--infra` WITH `--suite`:** Override the resolved profile's compose_profiles and rdbms with the infra values. For RDBMS inference: if any resolved profile is a known RDBMS profile (postgres14, mysql8, oracle), use it as the rdbms override.
   - **If `--dry-run`:** Skip container startup and InfraManager entirely. Still resolve profile and store in stash. The collection.py `pytest_collection_modifyitems` will handle printing the dry-run report and calling `pytest.exit()`.

3. In `pytest_configure`, when `--dry-run` is active: skip the entire container lifecycle block (both in-container InfraManager and host-side ContainerManager). Add an early check: `if config.getoption("dry_run", default=False) or config.getoption("dry_run_json", default=False): return` after storing profile in stash and configuring xdist.

4. Wire collection.py's `pytest_collection_modifyitems` hook: The simplest way is to ensure collection.py is loaded as a plugin module. In `__init__.py` or `plugin.py`, register collection.py's hooks. Recommended: In `plugin.py`'s `pytest_configure`, after profile resolution, do `config.pluginmanager.register(collection_module, "rucio_collection")` where `collection_module` is imported from `.collection`. This ensures the hook runs. Alternatively, since `conftest.py` already has `pytest_plugins = ("tests.ruciopytest.plugin",)`, change it to include `"tests.ruciopytest.collection"` as well.

5. Update `__init__.py` to export stash keys if they were moved there in Task 1.

6. When xdist is disabled and `--suite` is active, print info note: "xdist disabled, noparallel markers have no effect" in `_print_profile_summary`.

7. Update `_print_profile_summary` to also show `exclude_paths` when non-empty and `--infra` when specified.
